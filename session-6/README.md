## 📘 Session Overview  

This session delves into the foundational quantum algorithms that demonstrate the computational advantage of quantum mechanics over classical approaches. We will explore the concept of quantum oracles, the phase kickback technique, and detailed breakdowns of the Deutsch, Deutsch-Jozsa, and Bernstein-Vazirani algorithms.

---

## 🧠 What You Will Learn  

This session focuses on the first generation of quantum algorithms and the mathematical tools required to understand them.

### 🔹 Quantum Oracles & Phase Kickback
Understanding functions as unitary operators (black boxes) and the mechanism of phase kickback, where the eigenvalue of a target register is kicked back into the phase of the control register.

### 🔹 Deutsch Algorithm
Learning how to determine if a function $f(x): \{0,1\} \to \{0,1\}$ is constant or balanced with a single query, achieving a speedup over the classical requirement of two queries.

### 🔹 Deutsch-Jozsa Algorithm
Extending the Deutsch algorithm to $n$ qubits to determine if a function is constant or balanced, showcasing an exponential speedup ($O(1)$ vs $O(2^{n-1})$ classical queries).

### 🔹 Bernstein-Vazirani Algorithm
Discovering how to find a secret string $s$ embedded in a function $f(x) = s \cdot x \pmod 2$ using just one query, compared to $O(n)$ classical queries.

### 🔹 Implementation Details
Circuit construction for these algorithms, including initialization, Hadamard transformations, oracle application, and measurement.
