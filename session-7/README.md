## 📘 Session Overview  

This session introduces Grover's Algorithm, one of the most famous quantum algorithms, known for providing a quadratic speedup for searching unstructured databases. We will explore the principles of amplitude amplification, the geometric interpretation of the algorithm, and the detailed circuit construction required to implement this quantum search.

---

## 🧠 What You Will Learn  

This session focuses on solving the unstructured search problem using quantum mechanics.

### 🔹 Unstructured Search Problem
Understanding the challenge of finding a specific item in an unsorted database and how quantum computing addresses it more efficiently than classical methods ($O(\sqrt{N})$ vs $O(N)$).

### 🔹 Amplitude Amplification
The core mechanism behind Grover's algorithm. Learning how to iteratively increase the probability amplitude of the marked state while suppressing the others.

### 🔹 Geometric Interpretation
Visualizing the algorithm's steps as rotations in a two-dimensional vector space spanned by the initial state and the target state.

### 🔹 Circuit Components
- **The Oracle:** Marking the solution state by flipping its phase.
- **The Diffuser:** Inverting amplitudes about the mean to amplify the correct state.
